# Literal printed Greek
Read cards.jsonl in its given order. Each card has a full native line with the target outlined and a 3× word zoom. base_letters removes every combining mark; anchor_index counts letters from zero.
Transcribe ink, including misprints. Never infer marks from grammar. Give all four anchor_heads: breathing, accent, diaeresis (dialytika), subscript. Unknown is allowed for every head. Use literal with a complete transcription if no option is exact. A head set to a known value must match that transcription. Set ownership_ok to null for an unmarked anchor; otherwise true/false describes whether mark ink belongs to it. None means visibly blank. Give readability, confidence and a note; optional letter_heads covers other letters. Write exactly one answer per card in the assigned order, incrementally, to answers.jsonl. Set usage to {"input_tokens":0,"output_tokens":0}.
