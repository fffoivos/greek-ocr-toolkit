# Historical page reviews

These scripts reproduce prior round, coordinate, boundary and statistics reports.
They are preserved, not deleted or replaced with empty wrappers. Run their named
commands from the repository root using the original local fixtures, checkpoints
and receipts described in the corresponding committed report. Most are not
standalone tools for arbitrary new documents.

Their repository-root calculation now accounts for this archive directory.
Report commands and imported module paths have been updated. Source-image
receipts and committed JSON evidence retain their historical bytes.

For new page work use `greekocr pages`; for frozen Q1 statistics use
`scripts/glyphs/build_statistics.py`. Orientation remains parked and opt-in.
