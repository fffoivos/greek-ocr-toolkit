# O4c — bounded discovery of additional polytonic / Cyrillic scans

The ranked manifest is `docs/evidence/o4c/candidates.jsonl`; counts and transfer accounting are in `summary.md` and `summary.json`. Per-source JSONL retains unknown rights, unmeasured layers and rejected records. `discovery_merged.jsonl` deduplicates those discovery rows. The 107 S17 Parliament IDs and their content MD5 aliases are explicitly excluded from additional ranked supply. No scan corpus was downloaded, no training was launched, and no `.git` operation wrote state. O4b's files were not edited.

The motivation is E1 run4's 104 real polytonic and 11 real Cyrillic training lines, polytonic mark losses around 26–100% and Cyrillic heldout errors around 12–27%. This discovery does not turn library OCR into gold text. The text-layer exclusion in `docs/data_sources.md` concerns text seeds; here PDF text and DjVu coordinates are geometry and silver supervision for later adjudication.

## Schema (`o4c-1`)

One ranked row per additional document, sorted by descending `estimated_target_lines` (sum of measured/extrapolated polytonic and Cyrillic newline units), with deterministic source/ID ties. Identical selected scan MD5s or download URLs are deduplicated; `duplicates.json` records aliases. Different editions/scans/volumes remain separate documents. This is document-level discovery, not an accepted line inventory.

- `rank`, `candidate_id`, `source`, `document_id`, `title`, `record_url`, `metadata_url`: stable source identity and supporting API/page. Source IDs: Parliament UUID; IA item identifier; Anemi `.tkl` metadata path; Commons `File:` title; additional library-prefixed ID.
- `year`, `pages`, `size`, `download_url`, `scan_files`: publication/date-derived year, PDFium page count or API `imagecount`/bibliographic estimate, selected scan bytes and media URL. Unknown values are JSON `null`. Multiple files remain in `scan_files`; only one is selected/measured per document. IA derivative `Text PDF` is preferred. A metadata-listed media URL is a source declaration, not proof that we downloaded the PDF/DjVu.
- `rights.raw`: exact per-record strings/URLs, including null/missing fields; `identifier`: exact normalized version when present; `family`, `compatible`, `verification`. Allowed families: PD/CC0/CC-BY/CC-BY-SA. NC/ND are excluded. No-known-restrictions, missing rights, inferred PD from age, site openness and portal metadata licences do not establish compatible document rights. Contradictory all-rights-reserved declarations fail closed. Public Domain Mark is a source's PD declaration, not itself a copyright licence. Jurisdiction/underlying copyright are unverified beyond the declaration.
- `text_layer.status`: `verified` = actual nonempty layer/sidecar bytes measured, `declared` = API lists sidecar, `empty-sample` = sampled page empty, `unverified` = absent measurement or failed probe. `kind`, `measurement`, `sample_pages`, `page_indices`, `probe_bytes`, source URL/sha256 and `scan_status` distinguish PDF embedded text from external IA OCR. IA PDF embedded text remains explicitly `unverified`; the measured DjVu OCR sidecar is the silver layer used for S3 discovery.
- `polytonic_ratio`: Greek letters carrying a mark divided by Greek letters. Counts original letter-category Greek Extended U+1F00–U+1FFF or attached breathings/perispomeni; combining grave and iota-subscript also count. Ordinary tonos alone does not. Combining marks are attached to the immediately preceding Greek letter, with no double counting. Extended oxia counts in the requested codepoint diagnostic, so its acute-only encoding can differ from ordinary tonos. Greek Extended punctuation never counts. `cyrillic_ratio`: Cyrillic letters / all letters. NFD identifies base-letter script; original source text is preserved.
- `polytonic_document`: at least 50 sampled Greek letters and polytonic ratio >= 0.01; `cyrillic_document`: at least 50 Cyrillic letters and Cyrillic ratio >= 0.20. These are discovery thresholds, not orthography or OCR-quality certification. Source language metadata is retained; the target language is not independently adjudicated.
- `estimated_polytonic_lines`, `estimated_cyrillic_lines`, `estimated_target_lines`, `estimate_method`: Archive full sidecar newline census, or count of nonempty target-bearing lines on one PDF page times PDFium page count. They estimate silver units, not usable/adjudicated line crops. A mixed dictionary can produce many polytonic lines and rank above modern prose. `orthography_scope` makes that selection caveat explicit.
- `geometry_url`, `geometry_status`, `geometry_sample_sha256`: IA `_djvu.xml` and, where requested, a 128 KiB prefix proving `<WORD coords=...>` exists. Coverage/coordinate correctness for the whole document is unverified. No XML is treated as gold.
- `proofread_status`: Wikisource index/quality metadata if permitted by robots and available; levels 3/4 alone do not certify gold text. This run's live API join was blocked and all gold text is unverified.
- `field_verification`: per-field distinctions between source declarations, measured PDF page count/range access, target-script measurement and unverified edition, language or underlying-rights adjudication.
- `print_review`: image-bound manual review, with zero-based page indices, sample scripts, source/resolved URLs, local image paths and SHA-256. `unverified` means no visual adjudication; `verified-target-sample` verifies only the sampled print; `unverified-conflict` excludes an OCR/metadata false positive from ranking without claiming the entire book has no target script. `unverified-scan-origin` excludes digital-looking editions whose physical scan origin was not established. Whole-document language/orthography remains unverified. Reviews are recorded in `print_reviews.jsonl` separately from the raw OCR measurements.
- `media_probe`: Archive media URL access and PDF/DjVu signature verified by a 512-byte Range prefix, with resolved URL/hash/Content-Range in `media_probes.jsonl`. This verifies file format/access in this run, not full-file integrity or embedded PDF text. Failed/unperformed prefix checks remain `unverified`.
- `existing_s17`, `status`: baseline exclusion and `candidate-silver-needs-adjudication`. The main manifest requires compatible per-record rights, media URL, measured target-script text and an additional document. Archive records additionally require a reviewed physical scan page showing the target printed script (`print_review.status=verified-target-sample`) and successful bounded media access (`media_probe.status=verified-file-prefix`); OCR ratios and metadata-only media URLs are insufficient. All other rows stay in per-source/merged discovery, not in the ranked supply. After extending IA discovery, inspect bounded page probes, record reviews and verify media prefixes before rebuilding the ranking.

## Implementation and limits

`o4c_common.py` supplies the descriptive User-Agent `GreekPageOCR-O4c/1.0 (noncommercial OCR research; metadata and bounded text-layer probes)`, robots enforcement (longest-match wildcard rules), shared rate/transfer accounting, hashed HTTP recordings and offline replay. Requests start at least 0.6 seconds apart per host (never >2/s), increased by robots Crawl-delay/Request-rate. Redirect destinations check their own robots; unknown/failed robots fail closed. A cross-process lock protects the ledger and start times. Persisted rate timestamps use Unix seconds (`unix-seconds-v1`) so reboot/resume does not inherit stale monotonic clocks; a backwards wall-clock change waits a full interval. Use serial commands targeting each output: concurrent writers to the same JSONL are unsupported.

All attempts and changes of Range block size remain charged in the cumulative ledger. The cumulative task payload cap is 2,000,000,000 bytes. Metadata, robots, redirects, failures and aborted bounded reads count. Cache hits do not. Accounting counts bytes actually read, compressed if gzip is provided; it is not a TCP/TLS wire capture. A separate conservative reserve is documented in the summary for pre-ledger probes/transport overhead. **Do not remove/reset the transfer ledger to extend this task beyond its cap.** No automatic retry loop exists; `--retry-errors` retries cached 429/5xx or truncated responses on a later invocation with normal rate/budget checks.

Per-source transfer in the summary assigns early `recon` requests and redirect-host bytes to the relevant library by host. `transfer_by_source` preserves the original ledger process labels; `transfer_assigned_to_library` supplies the source totals. The pre-ledger reserve is separate, and any unknown host remains explicitly `unattributed`. These totals are checked against the ledger.

PDFium opens a seekable sparse HTTP Range file, capped at 4 MB per PDF open/probe attempt, and measures **one page** (zero-based index 2, or final available page for shorter PDFs). It detects a large raster image object covering >=50% of the sampled page, alongside embedded text. Ignored Range and malformed Content-Range fail closed. Custom PDFium callbacks return failure rather than passing partial/junk buffers to the C reader. There is no large full-PDF fallback. Opening a PDF still needs header/xref and sampled-page object bytes; those can include most/all of a very small PDF, but no other page is measured/rendered. IA probes read at most the full `_djvu.txt` (30 MB cap) plus a 128 KiB `_djvu.xml` prefix; only a 512-byte Archive PDF/DjVu header prefix is read to verify format/access, with no full-file fallback. Bounded JPEG page probes (8 MB cap each, at most three distinct pages per item including earlier attempts) support visual script checks. They use the same robots, rates and cumulative ledger; Archive transfer includes both `archive_visual` page bytes and `archive_media` prefix bytes.

HTTP cache: `docs/evidence/o4c/http/<sha256(URL + Range)>.{json,body}`. Receipts bind URL, Range, status, headers, fetched time, source, size and content hash. OCR text/PDF range bodies here are bounded probe evidence, not a corpus acquisition plan. Portable recorded excerpts and one CC-BY Parliament page are under `fixtures/`, with source URLs/hashes/attribution. `.state.json` stores query-specific cursor, requested row count and completion. Errors and failed/blocked interface attempts are in `<source>_events.jsonl`. A complete catalogue cursor does not certify a complete PDF-file census.

## Source findings and caveats

**S1 Parliament:** the live API identifies **DSpace 7.6**, not InvenioRDM; `/api/records` returned 404. Discovery uses `/records/api/discover/search/objects`; bundle/bitstream enumeration uses `/core/items/<UUID>/bundles` and `/core/bundles/<UUID>/bitstreams`. The existing S17 URLs remain valid. Rights vary: CC-BY exists but NC/ND also appears. Parent volume records may provide many page images with no original PDF; session records can provide PDFs. The unfiltered search reports 76,274 objects; only actual item records are saved. The large-page experiment exposed a server bug: requesting `size=1000` reports size 1000 but returns only 100 objects, risking skipped records. It was stopped, the last contiguous 100-row frontier restored, and a recorded-fixture regression now rejects any truncated nonterminal page. **Use `--rows 100`; do not trust reported large-page size. An attempted unique handle sort (`dc.identifier.uri,asc`) returned HTTP 422. Equal-title pages can overlap; IDs are deduplicated, but a traversed end cursor does not prove a snapshot-complete unique-item census.** Overall catalogue/file coverage and its exact cursor are in `summary.json`; no unprobed record has been counted as verified supply.

**S2 Anemi, authenticated continuation (8 October 2026):** the login form is fetched and submitted at its resolved `/login/` URL, using `ANEMI_USER` and `ANEMI_PASS` only through `os.environ`. Posting at `/login` loses the POST body on the trailing-slash redirect; authentication is accepted only when signed-in navigation appears, not merely because a cookie exists. The cookie jar and all authenticated raw response bodies remain in memory. No keep-me-signed-in field is submitted. macOS native verified TLS uses curl with an in-memory stdin configuration and stdout response stream: credentials/cookies never enter argv, temporary files, response-header files, fixtures, logs or notes. Ledger receipts retain public URLs, status, safe content headers, hashes and payload counts; no Cookie, Set-Cookie or redirect Location is persisted. Other platforms use Python's verified HTTPS opener. TLS verification is never disabled.

Requests start at least **two seconds apart**, including login, robots, redirects, errors and PDF page probes. The same shared process lock, Unix-clock rate state and cumulative ledger apply. The continuation cap is **1,500,000,000 bytes including the earlier O4c ledger**, rather than an additional 1.5 GB allowance. Metadata is resolved before probes; a bounded reserve prevents the final probe from overspending. `/tools/` and `/db/` are explicitly refused even if future robots rules change, and remain unqueried. The earlier three OAI guesses returned 404 and are not repeated.

The public advanced form supplies `datefrom`/`dateto`, `lang`, and material `collection` fields. Discovery traverses all requested result pages for each 1800–1809 through 1940–1949 decade, plus 1950 alone, in `gre` and `grc`, for monographs (`010`) and multi-volume editions (`020`). This is 64 query streams. Exact request URLs, source-reported totals, positional cursors and completion are in `anemi.state.json` and `anemi_events.jsonl`; document IDs are deduplicated across streams. A withdrawn slot displaying "Document is invalid after 2019-01-01" advances pagination but does not create a document. Search language/type/year classifications are source declarations; catalogue errors, mixed-language editions and Greek material catalogued only under other language codes remain possible. A traversed filtered census does not certify all Anemi holdings or a stable snapshot.

The site's bulk detail view merges bibliographic arrays and incorrectly repeats the first record's directory and viewer `rec` parameter across attachments. Therefore titles, authors and years are taken from individually identifiable overview rows. PDF files join only through a unique matching `metadata-*.tkl` / `attached-metadata-*` filename, never position. Canonical directory/viewer links are reconstructed from the record identity; the erroneous displayed links and reconstruction basis are retained in `scan_files`. Three separate individual source pages confirmed the reconstructed PDF URL, offered size and page count (`anemi_inventory_validation.json`). The 515,228,073-byte preservation master in the first fixture is distinct from its offered 5,768,787-byte PDF: the offered Download Document line controls `size`, not Preservation Info. Unknown pages/sizes/author remain null. Individual record-level rights are explicitly unverified when only a bulk inventory was inspected; aggregate rights fields trigger individual-record fallback. No age-based public-domain inference is made.

Full-PDF downloads invoke CAPTCHA even after authentication. The active public `showRecaptcha` function unconditionally resets/displays the CAPTCHA and creates a `/php/pdf_dump.php` POST form; its bounded account-free recording is `fixtures/anemi_download_control.js`. This continuation does not cross that gate. The ordinary View Document interface publishes `/php/pdf_split.php`, which serves a bounded PDF of selected pages. The viewer-to-filename template is verified against its actual iframe; at most three contiguous pages starting at zero-based index 2 (or the final available page for short books) are requested and decoded. Returned page count must exactly match the bound. PDFium measures each page's characters, Greek/polytonic/Cyrillic ratios using `o4c_common.metrics`, records per-page and combined measurements, and checks for a large raster object. Selected full-file pages/size remain source-declared; line estimates extrapolate the sample to that page count. A multi-volume catalogue record can list multiple PDFs: all stay in `scan_files`, and only the first offered PDF is sampled. **These are viewer-derivative PDF text-layer measurements. Original full-PDF embedded text, unsampled pages, physical-print language and scan provenance are not inferred from an empty or nonempty derivative sample.** Automatic raw PDF responses remain in memory; the explicitly recorded anonymous three-page fixture described below is the sole exception. Empty samples and unprobed documents remain distinct.

Final bounded result: **7,830 in-scope unique catalogue records**, **6,529 records with listed PDFs** (**7,612 PDF files**), and **411 sampled records / 1,231 original-page positions**. Of the samples, **one viewer derivative has nonempty embedded text**, **410 are empty**, and **zero meet the common polytonic-document threshold** (at least 50 Greek letters and polytonic ratio at least 0.01). **6,118 listed-PDF records remain unprobed**. The routine samples run newest publication year first, then stable ID (1934–1950 reached); one separately recorded 1809 viewer validation is also merged. This is not a representative estimate of historical holdings or original-PDF OCR coverage. There are 1,188 unknown authors and one listed PDF with unknown offered size/page count; these remain null.

All 64 filtered catalogue streams and all 118 nonempty-result media inventories were traversed; `probes_complete=false` and `stop_reason=transfer-budget-reserve` distinguish that completed metadata work from partial OCR sampling. The charged cumulative ledger is **1,495,620,394 bytes**, including **1,193,101,206 earlier O4c bytes**. Four legacy public-session cookie headers and three legacy redirect Location headers were removed from the earlier ledger without changing payload charges or response hashes; `anemi_privacy_redaction.json` records counts only. No new authenticated response stored such headers. The final offline fixture suite has **55 passing tests**. `anemi_audit.json` and `O4c_anemi_HANDOFF.json` bind the final evidence; the compatible candidate ranking remains 39 documents with no Anemi additions.

### Anemi terms and honest licence tier

The [Anemi home page's displayed access notice](https://anemi.lib.uoc.gr/) states exactly:

> © Anemi’s digital content is protected by copyright law. Access is provided solely for personal, educational or research purposes. Systematic storage or printing of the whole content of the digital items is strictly forbidden. Commercial use is strictly prohibited.

The exact notice, URL, fetch time and source-body SHA-256 are saved in `docs/evidence/o4c/anemi_terms.json`; its account-free recorded excerpt is `fixtures/anemi_terms.txt`. This expressly permits **personal, educational or research access**, subject to the stated restrictions. It **does not grant redistribution permission or a PD/CC licence**, and expressly prohibits commercial use and systematic storage/printing of whole digital items. Neither account access, publication age nor the availability of a viewer establishes broader reuse rights. The honest tier is **research-access-only**, with `rights.compatible=false` and `excluded-NC-or-ND`; Anemi records and measured layers remain in discovery evidence and a separate research table, but contribute **zero** to the compatible `candidates.jsonl` ranking. Whether the owner can obtain a separate redistribution/training licence is unverified.

`--max-pages` counts API/search pages per language/stream this invocation, not scan pages. `--probe-docs` is a per-invocation document cap; `--resolve-docs` caps new Parliament bundle-resolution attempts. `--all` completes metadata enumeration; it does not raise probe limits. `--resolve-all` separately enumerates compatible historical records' files. Changing IA rows requires a fresh output/stream; changing Parliament rows requires `--resize-page`, which rewinds to overlap and still validates actual response cardinality. This run's 1000-row API failure is why the continuation remains at 100.

If adding a new IA output such as `archive_broad.jsonl`, add its name to `o4c_finalize.INPUTS` before rebuilding; do not silently merge arbitrary JSONL/event files. Query hits, source-declared rights, measured silver text and verified/adjudicated gold stay separate. Multi-page proofread coverage, corrected line counts, legal/jurisdiction adjudication and training admission are unfinished downstream work.
