usage: verify_dev.py [-h] --release RELEASE --runtime RUNTIME --runtime-sha256
                     RUNTIME_SHA256 --panel PANEL --predictions PREDICTIONS
                     --predictions-sha256 PREDICTIONS_SHA256 --output OUTPUT

Clariden-only real-weight gate; load the final export through Docling's
recognizer. Uses byte-bound prepared005 dev PNGs, unchanged trainer collate,
fp32 CPU, NFD comparison. No test set loading, checkpoint selection, fetching
or submission.

  --release RELEASE
  --runtime RUNTIME
  --runtime-sha256 RUNTIME_SHA256
  --panel PANEL
  --predictions PREDICTIONS
  --predictions-sha256 PREDICTIONS_SHA256
  --output OUTPUT
