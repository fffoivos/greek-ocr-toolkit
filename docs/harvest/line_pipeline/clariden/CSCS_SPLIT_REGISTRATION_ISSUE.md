A complete input registration check should be distinguished from a sampled runtime qualification.

A diagnostic filtering census passed serial/parallel pilots on training and new-data parents but failed after 62 seconds when first registering a held-out parent. Its legacy split spelling had never crossed the canonical adapter in the sampled pilot. Startup tests and saved policy parity passed; no scientific decisions had been produced.

Experiment-owned workaround: explicitly map legacy evaluation aliases only with confirmed frozen parent cohorts, retain literal lineage, reject raw/book/row cohort conflicts, and add a metadata-only mode that uses the actual canonical adapter, ledger registration and correction-schema loader across every bound parent. It does not instantiate native workers or mark the filtering census complete. Freeze a new bundle and use a fresh output root; preserve the failed attempt.

Proposal for canonical readiness contracts: allow a science-owned complete-parent registration receipt to be required independently of sampled runtime/throughput qualification. The runner should verify its opaque digest and scope, not interpret foreign split spellings. No canonical source changes are proposed in this experiment.

Acceptance: a multi-parent fixture with an omitted-from-pilot malformed held-out split is rejected before full-run admission; coherent aliases stay evaluation-only; an incomplete or sampled registration receipt cannot satisfy the complete-input gate. Existing runtime qualification remains reusable when detector/runtime profile is unchanged.
