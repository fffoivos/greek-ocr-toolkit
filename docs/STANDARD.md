# Greek OCR tooling standard

Effective 8 October 2026: new OCR tooling belongs in this private repository, behind a small typed `greekocr` API and an offline pytest contract. A script alone is not the standard. Keep scientific logic, acquisition, interpretation, deployment plans and actual operational outcomes distinct.

Phase 1 preserves existing behavior. `greekocr/_vendor` is an implementation snapshot; the Docling plugin is a byte-identical runtime snapshot under `greekocr/deploy/docling_plugin`. Every copied file has its absolute origin, repository HEAD (or explicit absence), source state and source/vendored SHA-256 in `docs/INVENTORY.md` and `greekocr/_vendor/origins.json`. Relocated import hooks are part of import migration. Non-import AST hashes bind preserved logic; original recorded fixtures bind their response hashes. Keep upstream licenses and prior provenance files.

A future change must state whether it changes behavior. First add an independent regression fixture capturing the old contract. Keep a source-linked receipt for a vendor update, compare the exact old/new bytes and preserve the experiment identity. Do not silently repair normalization, script rules, quotas, admission gates, checkpoint tensors, native preprocessing or parity thresholds.

Recipe SHA-256 identifies the distribution. The mix validator still reads committed HEAD blobs under `factory/*.json`, never a working copy or index. `build_mix` and `validate_mix` require an explicit custody repository; it must contain the exact chosen recipe bytes committed at HEAD. A registry entry proves captured byte identity, not HEAD eligibility in another repository. Phase 1 makes no `.git` changes: the coordinator owns commits. Trainer failures occur before runtime initialization on invalid custody.

Real training shards come only from the existing Rust `linefactory import-real`. Preserve the reviewed canonical-work partition, compulsory O5/E1 and C1 exposures, byte-hash exclusions, exact shard inventory, provenance, spelling of `license`/`licence`, and factory-bound `word_tags.jsonl`. Keep geometric rejects even when two readers agree. Machine agreement remains `silver_agreed`; it is not human gold. Missing teachers and unsupported scripts remain flagged. Fallback tags are diagnostics, not a replacement factory receipt. Unknown rights remain unverified.

Scoring has two named paths. Strict E1 atom scoring consumes the reference label-ID decoding and predictions unchanged; non-NFD GT is an error. Bake-off scoring canonically decomposes both reader strings, preserves whitespace, and reports marks and Greek-to-Latin confusions. Never normalize a strict prediction to improve its score. Missing strata/mark support remain `None`, not zero.

Reader dependencies load lazily. Stage upstream checkouts, checkpoints, codec artifacts, CLLG README/contract and wheels locally on the worker. Native-framework references are independent of the converted preprocessing path. A shape/key match does not establish logits parity. Donor conversion retains backbone/neck tensors, changes the final head, binds the state digest and declares parity unrun until the separate 100-crop gate (with 20 independent preprocessing cases) passes.

Deployment plans are reviewable artifacts. Use environment secrets; never persist credentials in receipts. The new pod client is injectable, uses the original GPU/provider preference and payload rules, and writes only the caller's state path. Its original script is archived without execution. Historical node shells contain git resets and workload launches and are reference evidence, not runnable API defaults. This phase did not launch a pod, contact a source/service, build Rust, train, or use a GPU.

Operational watches follow checkpoint Part B: named DONE/FAILED/STALL/TIMEOUT/LOST events, finite loop bounds, bounded probes, SSH connection/keepalive/local timeout, measured log growth and explicit progress. They report stalls without killing workloads. A host Monitor, when used, expires within 30 minutes and must be re-armed after expiry until a direct probe confirms a terminal outcome. A toolkit watcher is not evidence that a host Monitor was armed.

Run `.venv/bin/python -m pytest -q` before handoff. Tests replay recorded fixtures and use mock transports/workers; the suite blocks sockets and live URL opens, uses CPU tensors, and creates no Git repository. Passing fixtures do not certify a production checkpoint, Linux/CUDA deployment, actual reader parity or a real Corpus extraction cohort. New operational qualification must carry its own bound receipts.
