## Data policy (the main removal)
Tracked data files dominate the repo: jsonl pools, census exports, keys, bundles of 90–477 MB each, 4.8–7 GB of tracked docs per branch, .git 3.6 GB. Rule after the clean-up: no tracked file over 5 MB; bulk artifacts (crops, pools, census exports, keys, bundles, HTML sheets, montages, pytest XML) live under an external data root with a receipt (path, bytes, sha256, producing commit) kept in `docs/records/`; `.gitignore` patterns + a size-guard test. History is not rewritten (the owner decides later whether to shrink `.git`).
