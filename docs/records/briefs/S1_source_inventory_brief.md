## Rules
- **Inventory only.** Metadata, catalogue queries, access-path checks and at most a 20-page image probe per source (bytes logged in a per-source receipt). No bulk downloads, no Google reads, no credentials stored. Respect robots and rate limits; identify with the project's contact User-Agent as in `greekocr.real.sources`.
- **Rights are recorded, not decided.** For each source and, where the source exposes it, per item: scan rights, text rights, access terms, whether cloud OCR processing is permitted, retention terms, redistribution terms; quote the terms page URL and the relevant sentence. Flag where Greek Law 2121/1993 Art. 21A/21B TDM exceptions might apply as "owner decision" — never assert they apply.
- Every number in the report has a receipt file.
