### 2. Recommended whole-word decision and fallback

**Use cached page-row geometry first, with row-owned visible body components as the deciding evidence.** This is the cheapest robust composition; a bare bbox-height fraction is only a candidate selector. It is more reliable than the present anonymous foreign-CC graph and does not require a new detector.

For crop C and overlapping neighbour N, compute body coverage over shared **occupied** x positions:

`v_N(x) = max(0, min(C.y1, N.baseline(x)) - max(C.y0, N.meanline(x))) / (N.baseline(x)-N.meanline(x))`.

Use the neighbour's own body height/x-height, original component extent, and the run's actual x positions. Whole-page averages and axis-aligned row bboxes lose the local information that matters on sloped rows: a small part of a row can contain one whole word even when its overall average overlap is low. A large envelope overlap can instead contain whitespace, detached marks or half-letters. The existing `magnitude.band_cut()` is the complementary guide-band calculation; `BoundaryEvidence.band/profile()` supplies original body ink and occupied intervals. The collector's `ownership()` fraction divides by **box height**, not neighbour height, so do not silently reuse that number as `v_N`. [C/collect_v3/vendor/geometry/magnitude.py:28–32](/Users/foivoskarounos-zamparloukos/Projects/greek-ocr-toolkit-sol-collect/collect_v3/vendor/geometry/magnitude.py:28) [C/collect_v3/vendor/geometry/ownership.py:50–77](/Users/foivoskarounos-zamparloukos/Projects/greek-ocr-toolkit-sol-collect/collect_v3/vendor/geometry/ownership.py:50) [R/greekocr/pages/boundaries.py:76–99](/Users/foivoskarounos-zamparloukos/Projects/greek-ocr-toolkit-sol-recut/greekocr/pages/boundaries.py:76)

Then preserve the neighbour's row/column/component identities and test a **single locally complete body run**, using existing letter/mark separation and measured gaps. The count, width and height thresholds are only a calibrated proxy for a word. They cannot establish that a whole word exists by themselves; do not require ten bodies, merge separate fragments across ordinary spaces, or count marks as letters. If a short/touching/ambiguous candidate cannot be resolved from recorded evidence, expose `unresolved` for adjudication rather than certifying absence. Two or more complete supported rows are the merged-line case regardless of which row's label Google returned.

`line_structure` / `boundary_evidence` supply the addressing, separators and physical profiles supporting that decision; they are not independent word recognizers. Q1B explicitly distinguishes real text crossings from unresolved **envelope** overlaps and found the strict “all crossings real” gate failed. Treating any crossing as bad would repeat that mistake. [S/docs/reviews/PAGE_LINES_Q1B_BOUNDARIES.md:109–125](/Users/foivoskarounos-zamparloukos/Projects/greek-ocr-toolkit-spellcheck/docs/reviews/PAGE_LINES_Q1B_BOUNDARIES.md:109)

**Fallback:** if saved geometry is absent but the native page and supplied boxes exist, prepare the existing detector/box-guided geometry **once per page in an explicit preparation stage**, outside admission and outside the live run tree, then consume the same adapter. If only the crop exists, use `column_segments()` → `line_glyphs()` / `baseline.text_lines()` (or `separate_lines()` plus its visibility outputs) and the existing component/letter tools. This is a lower-evidence fallback: crop-edge damage and ownership can remain unknown. Do not manufacture negative foreign ink from a missing neighbour. A prequalified crop-only fallback can decide; otherwise route unresolved, and fail qualification if unresolved cases are silently admitted.
