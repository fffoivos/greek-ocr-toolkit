## Construction and execution order

The opt-in path is now Q8 and approved B removals → printed boundaries → A faintness/reference → shared rows → legacy geometry in residual domains → recovery against current ownership → smoothing of residual/recovered items → residual B splitting → A on final footprints. It never calls the old unbend-and-Paddle field proposal or its early/late veto chain. It does not run the old final duplicate clipping on modeled bands. Default execution is kept separate and is checked against the saved R6 outputs.

`geometry_row_surface.NormalInk` is a typed input (`core`, `spread`, `boundary`, `support`). The row adapter requires it, including an explicit unknown value. `ink_faintness.analyze(require_reference=True)` uses A's existing calibration even when its faintness scout has no removal candidate; the default optional argument leaves A's previous behavior unchanged. No second normal-ink distribution is fitted on this path. Unknown calibration cannot authorize growth. The native endpoint measurement uses a grouped median of stroke-ridge contrast, replacing T2's incompatible mean-ridge statistic. Native component segmentation and calibration crop context are still not an exact replication of every A component witness; this remains a calibration limitation, not a claim of identical photometry.

Rows are nominated at approximately 12 pixels per provisional letter height. The native pass observes endpoints, complete components and gap obstacles. The native reference instead locates rows without reduction, with the same later ownership construction. Local height histograms, detached-mark pair tests, row-path interpolation and the independent column refinement in shared registration were vectorized. The outward correspondence initialization retains its sequential dependency. Native pixels still carry considerable cost; a validated cheap flat-page dispatch was not built here.

Layout no longer has T2's whole-region `unresolved_columns` veto. Repeated independent detector columns become modeled domains. Long printed rules and persistent native white channels establish columns. Short rules remain finite barriers. Table starts can create a horizontal domain transition only at a measured full-width white gap, rather than at a rule endpoint. No horizontal cut is manufactured at y=2091.5. Both adjacent domains follow the same measured rule path instead of independently using a median x-coordinate. The blank space between a running head and a page number can produce separate endpoint pieces. This is not yet a proof of correct full-leaf/header ownership on all spreads.

Every native component intersecting a domain is considered, including a connected component crossing a rule. A centre-only incidence had silently lost letters on the other side. A narrow rule seam separates the component graph before placing rows; it is **not** a permanent ink exclusion. Its h/8 width is a sampling-scale choice that still needs glyph-contact validation. Finite rules are verified using the existing straight/curved rule tools, supplemented by short vertical-run nomination. The M13 bilateral certificate is retained unchanged. The new nomination/partition does not certify that every stroke is front-page ink.

Found ink is distinct from new growth. Inside existing polygons, visible components below the normal mode are retained as ownership obligations. Outside them, a new end requires a native run of normal bodies. A parent cannot retire merely because one child touches one component: assembled crop coverage is checked before retirement and again after residual-domain subtraction. Every emitted modeled item has stable original source IDs and parent indices; an anchor is explicitly distinct from a recovered row's new evidence.

**The remaining defect is substantial:** an untransferred parent is retained as an explicitly unresolved residual. Its footprint is subtracted from modeled crops. This preserves found text more conservatively than T2's silent retirement, but can leave fragments or duplicates and retains wrong old geometry as a substitute. It does not satisfy the owner's instruction to model those regions. Keeping it visible is an experimental safety boundary, not a solution or a closed checklist item. Tiny seam-only pieces are not intended to be OCR rows; emission now requires an assigned component, with complete transfer audited afterward. This still needs the full native review below.

## Reuse and portability

Reused: A's calibration/classification and permanent exclusions; M13 and Q8 rule primitives; the shared displacement/obstacle representation; C's existing grid/residual/initial recoveries. The only A API extension requests its existing reference; default ink decisions were not retuned. The geometry joiner and smoother recognize modeled ownership and remain available outside it. No code was copied from another track into a private runtime snapshot.

`geometry_row_surface.py` is arrays plus typed records; `geometry_row_model.py` adapts legacy polygons and evidence. `median_by_label`, batched profile interpolation and the native obstacle reductions are reusable components. The full row adapter is **not ready as a production replacement**. OpenCV supplies connected components, morphology and rasterization; NumPy supplies scatter/interpolation; SciPy supplies filters, peaks and spatial queries; Shapely still supplies polygon Boolean operations, including exact hole partitioning. Rust must pin rounding, label order, border handling and Boolean semantics. This is a porting boundary, not a tested Rust implementation. Runtime dictionaries and residual ownership still need consolidation.

The next correctness work is to replace residual-parent substitution with one complete pixel/component-to-row ownership construction, reconcile native gap conflicts without shaving letters, and define column/header/table subdomains on the same surface. Then prove the approved recoveries and exclusions before attempting promotion. Speed work should avoid whole native censuses where only gap corridors/end regions need native pixels; vectorization alone did not achieve the charter target.
