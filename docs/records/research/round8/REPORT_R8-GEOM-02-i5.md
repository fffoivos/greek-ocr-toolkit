## What was implemented and exercised

The archived experiment retains the existing chain:

`compose → type_extended.recover → type_residual_recovery.recover(v11) → complete_request → native_bands → separate_bands → corridor_hulls/raster_envelope → refreshed admission checks → ordinary downstream compose`.

The new keyword mode is selected only by `complete_request`; default page-field M17 stays unchanged. `native_bands` and `separate_bands` receive explicit crop-coordinate axes, finite support intervals, accepted rule domains and target-row identities. `recover(complete_rows=False)` isolates the legacy configuration for differential runs; the integrated candidate enabled completion by default during the enabled 208 pass. It was a real live-call experiment, not a plotting-only or opt-in demonstration. None of these experimental API extensions remains installed after withdrawal.

1. **Finite rule ink edge.** Existing accepted path witnesses nominate their native M17 CC support. Per-row cross-sections locate the outer ink edge; missing cross-sections remain unknown. This avoids starting right support inside the witnessed bar. It does not discover arbitrary vertical ink, move the measured rule, cut joined glyphs or manufacture a full-height boundary. Preparation is shared once per witnessed rule.
2. **Whole support at interval ends/gaps.** Fragment spans are united with whole owned body/mark x support, including the upper-neighbour622/707 support omitted before. Crop origins, component labels, filtered residual-body positions and request/chain identities remain distinct. The admitted localization provides lateral search support before membership; owned labels alone cannot delete initial “το”. Finite gaps without opposed neighbour support are explicitly recorded, not called trusted full-width axes.
3. **Bounded native refinement.** Existing coarse valleys nominate a corridor. Crossed local spans are refined on the existing undilated M17 mean-mask ink at native resolution, within the current neighbouring axes, using the existing solver primitive. No full-plane Python DP or new ink threshold is introduced. Zero component crossing is required in request mode. The retained default tolerance and solver path remain unchanged outside it.
4. **Tight hull after membership.** Whole components contained by the proposed corridor, including unassigned marks, supply the archived i2 raster-envelope construction. They are not chosen solely by nearest-body semantic ownership. The final hull is checked against the admitted whole component set and corridor. Unknown containment does not become a letter class or front-source label. Missing/partial/shared support prevents a completion claim; unknown pieces keep their accepted legacy route.

All eligible pieces are collected into a fixed request census. One M17 mean/CC preparation and one batched call process 17 rows/7 targets. The fixed post-completion set supplies later neighbour/source/motif/barrier/duplicate checks. Changed geometry continues through ordinary B5 membership/anchors/votes, M35 population and footprints recomputation. No old row/source decision is cached. A support component from the residual closing mask is not silently treated as an M17 mean-mask label.

## Why the experiment is withdrawn

The two named origins alone were insufficient. A compact checked-in native fixture crops the exact M17 ink around φ/β from both request masks and tests all13 x-origin phases of the inherited coarse lattice. It exercises real `separate_bands`, clipping and final polygon fill. No synthetic font or widened crossing tolerance substitutes for native ink.

The main experiment fails at several phases: bounded refinement retains an incorrect coarse anchor or misses the needed endpoint span. A separately archived bounded endpoint retry expands refinement by the existing coarse-cell stride and removes those wrong anchors. It narrows the defect, but still fails the actual polygon consumer: **one φ pixel at native(2939,2759) is duplicated into the lower row**, while all 562β pixels remain there. `FINAL_COUNTEREXAMPLE.json` records a nominally accepted zero-crossing path and the wrong final raster membership; `phase-boundary.png` shows the pixel. One pixel is not waived. The statement that this last witness put two β pixels in the upper row was an intermediate diagnostic error; the saved final witness is the one φ duplication.

The full-caller hull verification can reject partial support, but that does not make the underlying separator contract generally valid. `experimental-source/` produced the successful four-row/208/timing evidence. `endpoint-attempt/` is a later, distinct source tested only on bounded native fixtures; **no208 or timing qualification transfers to it**. No further geometry design variant was attempted after this failure.
