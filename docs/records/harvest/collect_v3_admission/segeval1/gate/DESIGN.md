# SEG-GATE-1 design — written before implementation (19 October 2026)

Stage A uses the existing measurement-frame `line_glyphs` pass after the unchanged orientation/refocus path. `text_lines(glyphs, max_per_side=3)` supplies every row's side, votes, visible fraction and supported inclusive x-range; coverage is `(x1-x0+1)/width`. Components retain their toolkit roles and IDs. Assign each component once to the nearest detected body's centre at its centre x. Count bodies using `second_line`'s existing test: exclude marks/rules and widths >2 x-heights; intersection with that band's mean-to-baseline interval must be ≥0.6 x-height. A **complete** row needs votes ≥6, bodies ≥6, visibility ≥0.9 and coverage ≥0.6. These conservative support/high-visibility thresholds extend the existing refocus thresholds; six actual bodies and support across most of the width distinguish a printed line from a short fragment. This is a disclosed geometric proxy, not lexical truth.

For each non-main band, group only its `neighbour`-role components, ordered by x, at empty gaps ≥0.35 x-height (the existing `neighbour_words.row_word_evidence` / `WORD_PROXY.word_gap_xh` gap scale). Do not use `runs`' historical 3-x-height line-following gap as a word boundary. A group is whole iff it has ≥2 bodies passing the ≥0.6 overlap test and its extent touches neither horizontal crop edge; all remaining groups are cut-off. Keep group boxes, component IDs, qualifying body IDs and counts. Page-context reconciliation remains unchanged, is recorded per band and in aggregate when available, and never participates in the verdict. Report exact count agreement on all measured and resolved context pairs, including mismatches.

`skew_line(glyphs)` supplies main-row angle, all crossings, cut spans (`min_visible`) and cut letters (`body_cut`, `touches`). A baseline crossing whose meaning says “leaves the crop”, any cut span with min_visible <0.6, or row-frame height > upright height drops as `gate: target line cut`. Heights use the exact 0.6 `tight_box` pixel-cell method and unchanged main TEXT_ROLES; this preflight only evaluates clipping. Next drop complete non-main rows, then >2 whole neighbour words. Only absent/unsupported main rows or unresolved orientation abstain. Otherwise gate PASS. Do not treat an isolated cut-letter touch as a veto. Stage B alone computes the length features and calls the unchanged predictor; preserve its byte-identical length function/default 0.5–1.5 interval and the 0.6 padding formula/1.5 threshold. Prefix all final reasons by stage. Gate failures leave box/padding unavailable, explicitly skipped. Record inventory and gate before Stage B, including on failures.
