# Source inventory for data plan v2

The local commit is **blocked by the managed filesystem policy**: Git cannot create the worktree index lock. No worker commit or push exists. The [commit-block receipt](receipts/local/commit-blocked.json) and [source-bound handoff](commit_inventory.py) preserve the requested branch and exact commit scope.

Inventory of source access, rights evidence and bounded probes. “Done” means the requested source inventory and blocker ledger are delivered; it does not mean every route, right or yield is qualified. The [machine-readable records](sources.jsonl), [rights record](RIGHTS.md), [totals receipt](receipts/local/totals.json), [input hashes](receipts/local/input-files.json) and per-source assessments hold the supporting evidence.

The first pilots recommended are **IA historical Greek print**, **Ajax mixed-line ground truth**, and **BSB Philologus contents/body**. These are recommendations for the next owner-approved work, not acquisition or read authorisation. Numeric-source access qualification starts with ELSTAT; its page yield remains unknown.

Machine path **Y** means a fresh individual page raster was retrieved and decoded. It does not mean rights clearance or a usable OCR pipeline. Catalogue/table access and previously harvested images are recorded separately. **N** includes robots refusal, CAPTCHA/access restrictions, missing endpoints, timeouts, and routes for which only metadata or old images were verified. Print/digital counts describe only saved probe pages, never a repository proportion. Unknown target-class yield remains unknown.

All source HTTP requests use the unchanged project O4c User-Agent and robots/rate transport, with a separate receipt root in this worktree. No Anemi credentials were used; no Anemi images were requested. HF credentials were injected from Keychain into one command environment and were not recorded. No Google OCR/cloud reads, paid API use, production acquisition, gate acceptance, orders or messages occurred. The source-level image cap and byte accounting are checked in [validation](receipts/local/validation.json).

Probe totals count every saved witness once, including explicitly marked copies of existing local pages. Decimal MB is the sum of probe raster-file bytes; it is not total network traffic. The totals receipt separates newly fetched image bytes, local image bytes and recorded HTTP response-body bytes. TLS/header bytes and failed connection setup are outside that body-byte measure.

Edition dedupe is **not cleared**. The requested `collection/*/wave_manifest.json` paths were absent in this worktree and the read-only main checkout. Available `docs/records/harvest/*/books.json` and `source_books.json` plus O4c are hashed and compared conservatively. Missing authors/publishers prevent an absence-of-overlap certificate. Known identifier/title matches are flagged, including reused witnesses and the old IA lexicon. See [overlap inputs](receipts/local/overlap-inputs.json).

Key corrections are recorded below and in source assessments: IA Greek discovery was rebuilt rather than reusing the old Cyrillic-heavy list; current Patras domains and a Pleias digital-form licence were found; Pergamos has a working published-JPEG route but its sampled leaf is handwriting; Parliament licences vary even within proceedings; ELSTAT’s yearbook series begins later than its wider historical publication collection.
