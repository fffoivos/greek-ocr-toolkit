## 3. Bootstrap label policy (§2)

**Teacher:** frozen R1-A, with a **new** full-head export:
- all four heads' probabilities, plus margins and crop validity;
- the teacher hash and the calibration version.

The current export saves only the chosen value's probability, so it cannot be reused.

| Slot/head evidence | Label |
|---|---|
| blind printed target, ownership resolved | printed target (provenance kept) |
| reader = Google = named value, checks pass, admission cell passed audit | **pseudo-label** (never "print truth") |
| reader = Google = none | only from an audited shared-none cell; all-four-heads-none ≤ 60% of each new source's unique pool |
| reader adds or renames vs Google | queued by calibrated confidence; **blind-adjudicated** before admission; print wins |
| reader none, Google has a mark | no automatic deletion label; only print-adjudicated absence |
| low confidence, undecidable clipping, ownership unknown | excluded / quarantined |

**Confidence cutoffs:**
- Starting values: per head, p(top) ≥ 0.99 and top − second ≥ 0.20.
- Final values: replaced by thresholds fixed on the calibration cohort.

**Base alignment:** mark-blind and case-preserving, Google ↔ recogniser letters only. R1's full-NFD-equality gate is NOT reused, because
it would defeat the bootstrap. The recogniser supplies base-letter locations only (owner 08:50).

**Admission audit, before any student training:** 1,600 blind word cards, each with one anchor slot and all four heads read:

| Stratum | Cards |
|---|---:|
| Disagreements | 200 |
| High-risk agreed | 200 |
| Agreed named positives | 800 |
| Agreed none | 400 |

Gates (§2):

| Scope | Requirement |
|---|---|
| Overall | weighted error ≤ 0.5%, one-sided 95% upper bound ≤ 1% |
| Each named cell | upper bound ≤ 2% |
| Shared-none omission | upper bound ≤ 1% |
| Each source family | upper bound ≤ 3% |

- Zero-error cells get topped up: named cells to ≥ 150 cards, none cells to ≥ 300.
- The audit budget is capped at 3,200 cards.
- Failing or sparse cells stay out of training.

**Stop rule:** one teacher→student generation; 500k cap; no backfill from failed or unchecked strata.

**Cohorts:**

**Two outputs scored:**
1. **Raw reader:** exact named confusion matrices, atomic TP/FP/FN, composed-tuple accuracy; dialytika+acute separate from
   circumflex. Scoring uses a union of print and prediction slots under mark-blind base alignment, with UNKNOWN/coverage counts. The old
   physical-slot instrument stays as a continuity column. The 94.20% historical recall includes 206 apostrophe FN outside the heads, so a
   four-head result is reported beside it.
2. **Fixed correction pipeline:** same frozen policy for both checkpoints. Reports correct and incorrect additions and substitutions,
   recovered Google errors, regressions where Google was right, precision, yield, abstention, and subscript-addition precision on its
   own.

**Pass criteria (prospective margins; "inconclusive" does not adopt):**

| Check | Criterion |
|---|---|
| R2a target benefit | ≥ 30% fewer false target additions on the capital/ο/subscript-negative witnesses; ≥ 5 net fewer wrong target slots; document-cluster 95% interval excludes no improvement; positive strata preserved |
| R2b added value | ≥ 20% fewer named-mark FN on independently printed Google-omission strata, with no false-edit increase beyond the margins. EQ→OV must improve independently judged overrides. |
| Common-class noninferiority (classes with ≥ 200 support) | precision lower bound > −0.20 pp, recall > −0.50 pp, Holm-controlled |
| Sparse classes | no net increase in exact-name errors; every paired regression reviewed; labelled "unestablished" |
| Non-target protection | same margins; every regression on a preserved owner witness shown with its disposition |
| Coverage (CAL) | ≥ 95% of baseline correct accepted edits kept overall, ≥ 90% per supported class |
| Seeds | benefit in ≥ 2 of 3 seeds, positive mean, no seed over the non-target margins |
| Final | (i-b) and (ii) reported separately with uncertainty |

**Release check (winner only):**
- Rebuild only the frozen winner and diff every line and every changed atom.
- Run the box regression for integration.
- Do a fresh 100-line correction audit with weights.

## 5. Card tranches: Opus graders (§6, ruling 3)

**Card protocol:**
- Two blind readers per card; a third only on disagreement, resolved 2-of-3.
- Literal transcription of all four heads, plus ownership and readable / partial / unreadable states.
- Unboxed native word pixels plus line context. No model overlays, no "Google" label, no confidence.
- 10% pixel-verified controls per tranche, balanced among none, weak names and clipped cases; excluded from denominators.

**Document rules:**
- Documents come from outside every test set, and outside R1's 316 documents where possible.
- **Before any drawing**, a deterministic 10% of eligible new documents, stratified by source and era, is reserved for validation.
