"tracked/untracked" = `git ls-files` count / `git ls-files -o --exclude-standard` count (ignored files are shown separately). "last commit" = newest commit date touching any file under the path. Descriptions are taken from module docstrings, first Markdown lines, READMEs or JSON keys. Where no header exists the row says so.

Group keys: **G1** review/adjudication (cards, decks, sheets, owner notes, blind readers, print truth). **G2** recogniser + Google bootstrap (C1, CTC alignment, slot extraction, L1/L1E jobs). **G3** reader training/scoring, release gate, detector, K1, SF audits. **G4-*** everything else, each a separate group: `G4-spell` (S1 polytonic spell checker / v1 label-correction engine), `G4-glyphs`, `G4-geometry` (O4D), `G4-page-lines`, `G4-harvest`, `G4-readers`, `G4-research`, `G4-core` (package/infra).

**Scope warning.** The S8, L1R/L1R2/L1R3/L1R4, L1C, L1F and L1A2 tooling is **not on this branch**. It lives on unmerged siblings: `opus/spellcheck-s8` (37 commits ahead, 5,623 changed files, mostly `docs/records/labelfix/spellcheck`), `opus/spellcheck-l1f` (20 ahead), `-l1r3`, `-l1r2`, `-l1r`, `-l1`; also `sol/recut-v1` and `sol/l1e-mask` (`greekocr/glyphs/vertical_recut.py`, `foreign_ink.py`, `docs/records/harvest/recut_v1`). The s8 branch **modifies `greekocr/labelfix/case.py` and `ink.py`**, which are inside the frozen gate closure. A move done on this branch before those merges will conflict with all of them.

## 13. Evaluation of the proposed target layout

- `greekocr/review/`, `greekocr/bootstrap/`, `greekocr/reader/` + `greekocr/gate/` **do not fit the code as it stands.** Every `greekocr/*.py` is L1E-pinned. 14 labelfix modules are in the gate closure. The two import cycles cross the G2/G3 boundary. **Suggested change:** keep `greekocr/labelfix/` byte-identical as the frozen implementation. If grouping is wanted, add thin facade packages that only re-export, e.g. `greekocr/review/__init__.py: from greekocr.labelfix.deck_serve import *`. New code goes into the new packages from now on. Only the six G1 modules outside the closure (`deck, deck_serve, ingest_decisions, pull_firefox, sheet, owner_slots`) could ever move, and only with shims plus an explicit receipt-is-historical rule.
- `scripts/review/`, `scripts/bootstrap/`, `scripts/reader/`: feasible only for the 12 unpinned scripts listed in section 10, plus new work. `scripts/labelfix/clariden/*` → `scripts/clariden/<job>/` would break every C1/R1/L1E receipt and the POLICY digest. **Suggested change:** freeze `scripts/labelfix/` as is; put new job dirs under `scripts/clariden/<job>/`, which keeps the depth-3 root discovery, starting with the S8/L1F jobs when they merge, if that has not happened yet.
- `docs/records/review/`, `docs/bootstrap/`, `docs/reader/`, `docs/records/archive/`: `docs/records/archive/` is the main lever and is safe for leaf items with no live code refs (sections 4–7 mark these). Large candidates by size: `S7_evidence` 884M (negative result; `test_sf2` reads one 1-file input, so move that file or keep a stub), `S2_engine` + `S3_engine` 50M, `R0_cards` 48M (G1, keep while R0 truth is reused), `sheets/` 31M, `crops_S2` 3M, `review_deck` 6M, PAGE_LINES Q1–Q5 + evidence ≈ 6M, CP-G/CP-H1 reviews. **Archiving does not shrink `.git`** (section 8c). If repository size is the goal, the decision is an LFS/filter-repo migration of `docs/records/harvest/**` and `S7_evidence/**`, not a reorganisation.
- Deletion candidates (generated only): the four `docs/*pytest-results.xml` (small), `.pytest_cache/` 540K, `__pycache__/` (102 dirs, ignored), `.cache/m2_*.log` 16K, and the empty `artifacts/labelfix_l1e/verification_v4/`. **Not** deletion candidates despite looking like caches or outputs: `.cache/labelfix/**` (R1-pinned, 54 code refs), `artifacts/labelfix_r1/output_3678928/**` (untracked, read by sf4/sf5/sf6 measure), the `artifacts/labelfix_l1e/*.tar*` and `labelfix_sf3/*.tar*` files (hashed in `SF6c_evidence/runtime_audit.json`).

## 14. Hazards (summary)

1. **Unmerged sibling branches.** S8/L1F/L1R/L1C tooling and about 5.6k docs files are on `opus/spellcheck-s8` / `-l1f` / `-l1r*`. That branch edits the gate-closure files `case.py` and `ink.py`. Merge first, then reorganise, or every move becomes a conflict.
