# CU4: shared offline adjudication

The additive `greekocr.adjudicate` package, three data-spec re-emissions and API documentation are implemented. All three re-emissions have zero content differences. Existing builders and frozen code remain unchanged.

Workspace: `opus/cleanup-1`, starting HEAD `b16043641e3916aeee3e633e4400753d3208b69b` (CU4 brief directly above CU3 `7bc40ddc2`). No `.git` writes, commits, pushes, network access or model inference. R0, R1, S8 and R2C evidence was read only; no R2C deck or reader folder was modified.

## API and custody

| Entry | Contract |
|---|---|
| `owner_sheet.render(lines, spec) -> str` | Ordered groups/cards; named text rows with changed/no-ink segments, tags, optional Printed/zooms/clean magnifier; one unique note document per card |
| `owner_sheet.detection_image(image, slots)` | Saved above/apostrophe green, below blue, attached grey boxes and slot numbers; no detector execution |
| `deck.build_deck(spec) -> dict` | Named profiles, shuffled data/controls/options, opaque IDs, PNG-content hashes, exclusive sibling private key; leak/schema/zoom/fraction checks; viewer, manifests, instructions/schema and receipt |
| `deck.crop_image` / `deck.leak_scan` | R0 .6-height horizontal pad/full native height, <=3x LANCZOS/900 cap; native line/page; text/path/PNG metadata scan |
| `protocol.adapt_answer` / `deal` | Canonical, R0, S8 and R2C aliases; confidence high/medium/low; code-emitted reverse reader-2 order |
| `protocol.tiebreak_deck` | Fresh positions/options; own exclusive private map to original identities; includes controls |
| `protocol.controls_gate` / `resolve` | Both readers gated before votes; full coverage/order, 2-of-2 else 2-of-3, controls excluded, UNKNOWN preserved; third-reader mapping and controls independently checked |
| `score.wilson` / `score.score` / `score.clopper_pearson_lb95` | One implementation each; exact z; S8 document/line bootstrap, fixed weights, Wilson-Kish boundary fallback; one-sided exact LB95 |
| `protocol.write_truth` | Exclusive JSONL/deterministic gzip writer; reader observations, verdict/status/control fields and returned summary; refuses failed gates |

The full record/spec contracts and examples are in [the package README](../../../greekocr/adjudicate/README.md) and [generated API](../../API.md). `protocol.score` re-exports the sole estimator. All 14 new public callables are typed, importable and documented; all 296 prior callable sections are unchanged, and generation is idempotent. [API verification](../../../artifacts/cleanup_step4/api_validation.json).

Packaged assets are real `owner_sheet.css`, `owner_sheet.js` and `deck.js`; setuptools includes them. There is no production `src.split` extraction or runtime dependency on a historical builder. Autosave uses `notes/{line_id}` or `notes/{line_id}:s{slot}`, merge writes, 900 ms debounce, blur flush, serialized in-flight writes, and load-race protection. Printed is saved with `printed_edited`. The magnifier retains clean pixels, Z=3, a 300x130 lens and tap toggle.

Historical C1 gates are descriptions through `readers=1`, `min_n`/`exact_n`, explicit rate thresholds and `allow_no_controls`. They do not reduce the new-deck owner rule: every new deck has two independent readers and an independent tiebreak for disagreements. No old gate or old scientific result is relabelled.

### Non-content differences and protocol changes

Every changed card DOM attribute is listed under `non_content_element_changes` in each owner diff, separately from the zero content differences. The accent sheet gains accessible Note label/textarea IDs; all note data attributes and database document identities remain identical. Other HTML changes are the doctype/head/body/UTF-8/viewport wrapper and serialization whitespace. Shared package CSS adds muted text color and fixes zoom width specificity while preserving light/dark tokens. The external font stylesheet link is removed for offline use. The script reads individual note documents instead of a 1000-document collection query, protects typing during load, serializes saves, stores `printed_edited`, and fixes touch tap toggling. Original image pixels, clean crops, lens size and magnification are unchanged. These UI/persistence changes are explicit; content parity is not browser-visible layout or live artifact-db proof.

R0 image basenames change from sequential names to encoded-content hashes; all 672 old/new view names and pixel results are mapped in the full diff. Re-encoding strips metadata. The private key remains write-once in a sibling tree, as in R0-ib: no key-relocation improvement is claimed for that deck. The new shared instructions/schema/viewer and explicit reader-2 reversal are **protocol changes**. The replay deliberately preserves historical item/options/control order; new decks shuffle all three, and new tiebreaks change multi-option order. New resolution uses literal-form controls rather than silently reusing the historical R0 bare-letter control gate. Old reader answers are not rescored or upgraded.

The leak scan covers text, paths and PNG metadata, not semantic recognition of printed book content. Sibling private files are still reachable by an explicit path when readers have full filesystem access, as the blinding audit explains. Only the blind tree and an isolated own-output location should be handed to a reader. No live reader job was started.
